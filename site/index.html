ターミナルで駆けろ、銀河の最前線へ。
ストーリーモード・武器進化・アイテム搭載の本格 ASCII シューティング

npx galaxy-strike

FEATURES 特徴

🎮

ストーリーモード

全5ステージ。パイロット「カイト」とオペレーター「ミア」の台詞と共に、帝国機甲軍団「バルガン」の母艦を目指す。

SECTOR-01 → 05

🛠️

武器進化

ステージクリアごとに射撃パターンが進化。単発から始まり、最終的には五方向×貫通の最強弾「ノヴァブリッツ」へ。

Lv1 → Lv6

👾

ボス戦

各ステージの最後には巨大ボスが待ち受ける。難度はステージが進むほどスケーリングする敵AI。

WATCHER / NEBULA / IRONWALL / GRAVITY / VULCAN

💎

アイテム

敵撃破で 25% ドロップ。ライフ回復・10秒パワーモード・オーバードライブを駆使して生き残れ。

♥ P ★

ITEMS ドロップアイテム

      

        

          
♥

          
ライフ回復

          
ライフを1個回復。最大5個まで、超過分は +500点に変換。

        

        

          
P

          
パワーモード

          
10秒間、七方向×貫通の最強弾に変化。敵を一掃せよ。

        

        

          
★

          
オーバードライブ

          
10秒間、最強弾 + 無敵。レアドロップ。取り逃すな。

        

      

      
敵撃破時に 25% の確率でドロップ。ボスは確定でライフを落とす。

    


    
    

      
INSTALL インストール

      

        
npx でダウンロード不要、すぐに遊べます。

        
npx galaxy-strike

        
グローバルインストールして何度も遊ぶなら:

        
npm install -g galaxy-strike
galaxy-strike   # または gstrike / game
